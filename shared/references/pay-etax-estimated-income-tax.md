# pay-etax-estimated-income-tax

日本の個人所得税の予定納税を、e-Taxソフト(WEB版)とインターネットバンキングで進めるための手順。特にMac版Safariの環境準備、白画面の復旧、納付情報登録依頼、受信通知の確認、金融機関への安全な引き継ぎを扱う。

## 使う場面

- 「予定納税をe-Taxで払いたい」
- 「予定納税の第1期または第2期をインターネットバンキングで納付したい」
- 「Safariでe-Taxのボタンが動かない、画面が白い」
- 「納付区分番号通知から銀行の画面まで進めてほしい」

## 対象外

- 予定納税額そのものの計算や税務判断
- 予定納税額の減額申請
- 確定申告書の作成や送信
- 振替納税、クレジットカード納付、ダイレクト納付の新規登録
- 銀行へのログイン、ワンタイムパスワード入力、最終的な支払い確定

対象外の依頼では、このskillを無理に適用せず、税理士、所轄税務署、または該当する別の手順を案内する。

## 入力

作業開始時に、ユーザーが提示した通知書またはe-Tax画面から次を確認する。

- 対象年
- 予定納税の期別
- 納付金額
- 納期限
- e-Taxにログイン済みか
- 利用する端末とブラウザ
- 既存の「予定納税に係る納付区分番号通知」があるか

金額、期限、期別は前回値を流用しない。毎回、当年の通知書またはe-Taxの通知を正として確認する。

## 出力

- e-Taxの納付情報登録依頼が正常に受け付けられた状態
- 受信通知(納付区分番号通知)で税目、期別、課税期間、金額を確認した状態
- インターネットバンキングの金融機関選択画面、または銀行ログイン画面への引き継ぎ
- ユーザーが保存すべき受付結果と納付完了画面の案内

## 重要な安全ルール

1. 国税庁とe-Taxの公式サイトを優先し、期限や推奨環境は作業時点の最新情報を確認する。
2. 利用者識別番号、納税用確認番号、マイナンバー、銀行認証情報を回答本文へ転記しない。
3. e-Taxへの送信直前に、税目、対象年、期別、金額、提出先を提示して明示確認を取る。
4. 銀行ログイン、ワンタイムパスワード、最終支払いは必ずユーザー本人へ引き継ぐ。
5. 送信または納付の途中で中断した場合は、現在画面と受信通知を確認してから再実行する。二重送信と二重納付を避ける。
6. 「送信完了」と「納付完了」を区別する。e-Taxの納付情報登録依頼を送信しただけでは納税は完了していない。
7. ブラウザ画面を操作する場合は、利用可能なら `computer-use:computer-use` skillを先に読み、その確認ポリシーに従う。

## 手順

### 1. 最新情報と既存通知を確認する

1. 国税庁の公式ページで、e-Taxソフト(WEB版)の推奨環境、利用可能時間、障害や保守情報を確認する。
2. ユーザーにe-Taxへのログインを依頼する。認証操作はユーザー本人が行う。
3. ログイン後、次の順に既存通知を探す。
   - `送信結果・お知らせ`
   - `お知らせ・受信通知`
   - `予定納税等通知書`
   - `予定納税に係る納付区分番号通知`
4. 対象年、期別、金額が一致する既存通知があれば、新しい納付情報登録依頼を作らず、その通知から進む。
5. 通知がなければ、納付情報登録依頼を新規作成する。

### 2. Mac版Safariの環境を整える

1. 国税庁の推奨環境ページで、現在のmacOSとSafariが対象か確認する。
2. e-Taxの環境チェックで次を確認する。
   - ブラウザ拡張機能が正常
   - 事前準備セットアップが正常
3. 未導入なら、国税庁公式配布のMac用事前準備セットアップを導入する。
4. Safariの機能拡張 `e-Taxソフト(WEB版)` を有効にする。
5. 機能拡張のWebサイトアクセスを、少なくとも次のe-Taxドメインで許可する。
   - `login.e-tax.nta.go.jp`
   - `clientweb.e-tax.nta.go.jp`
   - `mypage.e-tax.nta.go.jp`
   - 前回「1日だけ許可」を選んだドメインは、次の期までに権限が失効する。毎回確認し、ユーザーが同意する場合は公式e-Taxドメインだけを常に許可する。
6. e-Taxサイトでは、JavaScriptとポップアップを許可し、コンテンツブロッカーを一時的に無効化する。
7. 設定変更後はSafariを完全終了して再起動し、ログインし直す。

### 3. 白画面または無反応を復旧する

`申告・申請・納税` を押しても動かない、またはサブメニューが白い場合は、次の順で確認する。

1. Safariを再読み込みする。
2. Safariを完全終了して再起動する。
3. Safariの表示言語を日本語にする。
   - macOSのアプリ別言語でSafariを日本語に設定する。
   - またはシステムの優先言語で日本語を最優先にする。
4. Safariを再起動してe-Taxへログインし直す。
5. e-Tax機能拡張と事前準備セットアップの環境チェックを再確認する。
6. サイト別の機能拡張アクセス、ポップアップ、コンテンツブロッカーを再確認する。
7. それでも直らない場合は、国税庁の最新FAQと推奨環境を確認し、推奨外バージョンならユーザーへ明示する。

今回の実測では、機能拡張と事前準備セットアップが正常でも、Safariが英語表示のままだと `申告・申請・納税` のサブメニューが白くなった。Safariを日本語表示にして再起動し、再ログインすると表示された。白画面では言語設定を早い段階で確認する。

### 4. 納付情報登録依頼を新規作成する

1. `申告・申請・納税` を開く。
2. `納付情報を登録する` の `納付情報登録依頼(納税手続の開始)` を選ぶ。
3. 登録済みの提出先税務署を確認して次へ進む。変更は根拠がある場合だけ行う。
4. `新規に納付情報登録依頼を作成する` を選ぶ。
5. 税目で `申告所得税及復興特別所得税` を選ぶ。
6. 課税期間に対象年を入力する。
7. 申告区分で対象の期別を選ぶ。
   - 第1期は `予定1期`
   - 第2期は `予定2期`
8. `本税` に通知された金額を入力する。
9. 画面の自動計算後、`合計` が本税と一致することを確認する。
10. 加算税、重加算税、利子税、延滞税は、通知や税務署の指示がない限り入力しない。

### 5. 送信前に照合する

確認画面で次をすべて読み上げ、ユーザーの明示確認を取る。

- 手続名称: 納付情報登録依頼
- 提出先税務署
- 税目: 申告所得税及復興特別所得税
- 課税期間
- 申告区分: 予定1期または予定2期
- 本税
- 合計

確認を得るまでは `送信` を押さない。

`利用者情報の確認・変更` を開くと別タブが増えることがある。元の画面で「現在、別のウィンドウが表示されています」と出た場合は、確認用の別タブを閉じてから続行する。

### 6. 送信結果を確認する

1. ユーザーの明示確認後、`送信` を押す。
2. 確認ダイアログでも送信を確定する。
3. 即時通知で次を確認する。
   - `送信が完了しました`
   - 受付日時が表示されている
   - 受付番号が表示されている
   - エラー情報が空
4. `受信通知の確認` を押す。
5. 受信通知(納付区分番号通知)で次を再確認する。
   - 納付先
   - 税目
   - 申告区分
   - 課税期間
   - 合計金額
   - 納付区分
   - 有効期限
6. 個人識別情報や確認番号は、必要があってもチャット本文へ転載しない。

### 7. インターネットバンキングへ引き継ぐ

1. 受信通知の `インターネットバンキング` を押す。
2. e-Gov電子納付の金融機関一覧を開く。
3. 金融機関の種別を選ぶ。
4. ユーザーが銀行名を指定した場合だけ、その銀行のネットバンキング入口を開く。
5. 銀行ログイン画面の前でユーザーへ操作を返す。
6. 次の操作はユーザー本人が行う。
   - 銀行ログイン
   - 認証情報とワンタイムパスワードの入力
   - 税目と金額の最終確認
   - 支払い確定

### 8. 完了を確認する

1. ユーザーに銀行側で `納付完了` が表示されたか確認する。
2. 完了画面、取引結果、日時を保存するよう案内する。
3. e-Tax側の受信通知も保存するよう案内する。
4. 同じ期別の納付手続きを新しく作らないよう注意する。
5. 次の期別が残っている場合は、期別、金額、期限を次回あらためて通知から確認する。

## 次回の第2期で最初に行うこと

1. 第1期の納付情報を再利用しない。
2. `予定納税に係る納付区分番号通知` に第2期分があるか最初に確認する。
3. 期別が `予定2期` であることを確認する。
4. 第2期の金額と納期限を当年の通知で確認する。
5. Safariの言語が日本語のままか、e-Tax機能拡張が有効かを確認する。
6. 既存通知があれば、納付情報登録依頼を作らず直接インターネットバンキングへ進む。

## トラブルシューティング

| 症状 | 主な確認点 | 対応 |
|---|---|---|
| `申告・申請・納税` が反応しない | Safariの言語、機能拡張、事前準備 | 日本語表示、再起動、再ログイン、環境チェック |
| サブメニューが白い | Safariが英語表示 | Safariを日本語に変更して完全再起動 |
| 環境チェックがNG | セットアップまたは機能拡張 | 国税庁公式セットアップを再導入し、拡張を有効化 |
| ボタン押下後に進まない | 別タブまたは確認画面 | タブ一覧を確認し、不要な別タブを閉じる |
| 受信通知がすぐ出ない | 受付処理中 | 少し待って再確認し、送信結果・お知らせから探す |
| 金融機関へ進めない | Pay-easy対応、保守時間 | e-Govの金融機関一覧とe-Taxの保守情報を確認 |
| 途中で操作が中断した | 送信済みか不明 | 再送信せず、受信通知と受付番号の有無を確認 |

## 検証

### 送信前

- 税目が `申告所得税及復興特別所得税`
- 対象年が通知と一致
- 期別が通知と一致
- 本税と合計が通知額と一致
- 提出先税務署が登録内容と一致
- ユーザーから明示的な送信許可を得た

### 送信後

- 即時通知に送信完了が表示された
- 受付日時と受付番号が表示された
- エラー情報が空
- 受信通知の税目、期別、対象年、金額が一致

### 納付後

- 銀行側で納付完了が表示された
- 完了画面または取引結果を保存した
- 同じ期別の別手続きを作成していない

## 失敗時

- 推奨環境外の場合は、推奨外である事実と確認したバージョンを明示する。
- 送信済みか判断できない場合は、再送信せず受信通知を確認する。
- 金額、期別、期限に疑義がある場合は、入力を止めて通知書または所轄税務署で確認する。
- e-Taxまたは銀行の障害時は、公式の稼働状況と保守情報を確認する。
- 納期限当日に解決しない場合は、所轄税務署へ連絡するよう案内する。

## 発火テスト例

### 発火すべき依頼

- 「予定納税の第2期をe-Taxで払いたい」
- 「Safariでe-Taxの申告・申請・納税が白画面になる」
- 「予定納税の納付区分番号通知から銀行まで進めて」
- 「前回と同じように予定納税をインターネットバンキングで払いたい」

### 発火すべきでない依頼

- 「今年の所得税はいくらになりますか」
- 「予定納税の減額申請書を作って」
- 「確定申告書を作成して」
- 「住民税をクレジットカードで払いたい」
